# Макеты интерфейса после редизайна (issue #20)

Текстовые wireframes целевого интерфейса на ширинах 1440, 768 и 390 CSS px. Это план, а не описание текущего
сайта: функции появляются по шагам стопки PR, итоговые снимки синтетических данных находятся в `docs/design/screens/` (ссылки ниже).
Решение о библиотеке компонентов и результаты проверки — в [ui-decision.md](ui-decision.md).

Тексты интерфейса — как в UI. Числа в примерах («730 из 1380») иллюстративны.

- Порог раскладки — 1224 px, как сейчас: от 1224 px — боковая панель фильтров, меньше — кнопка «Фильтры · N» и выезжающая панель.
- Карточка компании на ширине от 1224 px — правая колонка 300 px. Она видна всегда и закреплена при прокрутке (`position: sticky`); пока компания не выбрана, в ней подсказка.
- Карточка на ширине меньше 1224 px — над представлением и только когда компания выбрана.

## 1440 — «Компании», вид «Карта»

```text
┌ RndTech · Исследование ИТ-сообщества   [Компании] [Состав выборки] [О данных]      [Светлая тема] ┐
├ Год исследования (2022|2021|2020|2019)  Сравнить с [нет ▾]                                        │
│ 2022 · Ростов-на-Дону, 20–44 года · Выборка: 730 из 1380                          [⧉ Дублировать] │
├──────────────┬──────────────────────────────────────────────────────────┬────────────────────────┤
│ ФИЛЬТРЫ      │ [Город: Ростов-на-Дону ×] [Возраст: 20–44 года ×] [Сбросить ограничения]           │
│ Город  [▾]   │ Компании [Все компании ▾] [Прежний набор: 29] [Показать все компании]              │
│ Возраст[▾]   │ Найти компанию [▾]  Показатель (Рек.+хотят|Рекомендуют|Хотят)  Вид (Карта|Таблица) │
│ Образов.[▾]  │ ┌────────────────────── карта, ширина контейнера ───────────┐ ┌ Карточка ─────────┐ │
│ Опыт   [▾]   │ │ ось Y: «Рекомендуют + хотят работать (сумма долей)»     │ │ Выберите компанию │ │
│ Профес.[▾]   │ │ • точки фирменного цвета, без подписей                  │ │ на карте, в       │ │
│ Язык   [▾]   │ │ ◉ выбранная: крупнее, обводка, подпись                  │ │ таблице или через │ │
│ Митапы или   │ │ ось X: «Узнаваемость» 0…100 %                           │ │ поиск             │ │
│ сообщество[▾]│ └──────────────────────────────────────────────────────────┘ └───────────────────┘ │
│ БЫСТРЫЙ ВЫБОР│ Доли — от числа ответивших о компании … Подробнее                                  │
│ Исходная выб.│ «Рекомендуют + хотят» — сумма двух долей … Подробнее                               │
│ Все участники│                                                                                    │
│ ГОТОВЫЕ ГРУП.│                                                                                    │
│ Таганрог,…   │                                                                                    │
└──────────────┴────────────────────────────────────────────────────────────────────────────────────┘
```

Точки — фирменного цвета компании. Подпись есть только у выбранной или найденной компании. Её буквы фирменного цвета с контрастной обводкой цветом текста темы.

Вид «Таблица». На месте карты — таблица из 7 колонок: Компания, Знают, Рекомендуют, Хотят, Рекомендуют + хотят, Сила бренда, Рейтинг бренда.
- Высота — по содержимому, шапка закреплена при прокрутке.
- Карточку открывает щелчок по строке или кнопка-имя компании; выбранная строка подсвечена.
- Под таблицей — пояснение «Сила и рейтинг бренда — индексы, не проценты людей».

Сравнение (выбрано «Сравнить с 2021»).
- У компании две точки на общей шкале Y: ● основной год (заливка фирменным цветом) и ○ год сравнения (кольцо фирменного цвета). Легенда — «● 2022 ○ 2021».
- В таблице под значением основного года — «Δ +2.5 п. п.» для долей или «Δ +12.3» для индексов. Если компании нет в одном из лет — «Нет данных за 2021 год».
- Если один из годов — 2019, вторая строка есть только у «Хотят». Над таблицей — «С 2019 годом сравнивается только «Хотят работать»».
- Карточка показывает оба года, у каждого свой N.

```text
│ [Фильтры · 2] [Город: Ростов-на-Дону ×] [Возраст: 20–44 года ×] │

│ Компании [▾] [Прежний набор: 29] [Показать все компании]        │

```

Таблица компаний на всех ширинах прокручивается по горизонтали нативно внутри своего контейнера, страница — нет. Все семь колонок остаются, ни одна не закреплена; шапка и строки прокручиваются вместе. Это решение PR5-TBL, принятое владельцем после проверки [ui-decision.md](ui-decision.md). Основные действия на сенсорном экране — не меньше 44×44 px.

## Панель «Фильтры» (меньше 1224 px)

```text
┌ Фильтры ───────────────────────────────────── [×] ┐
│ Город [▾] … Митапы или сообщество [▾]              │
│ Быстрый выбор: [Исходная выборка] [Все участники]  │
│ Готовые группы: …                                  │
├────────────────────────────────────────────────────┤
│ [Показать результаты]                    [Отмена]  │
└────────────────────────────────────────────────────┘
```

- Правки в панели — черновик. «Показать результаты» применяет их одним действием: 2 POST.
- «Отмена», Escape, крестик и щелчок по фону ничего не меняют. Фокус возвращается на «Фильтры · N».
- Escape в раскрытом списке поля закрывает только список: панель и черновик остаются.

## «Состав выборки» (все ширины)

```text
Город — сервер возвращает до 10 крупнейших городов по 2021 году; список неполный.
┌ Город ────────────────┬ 2022 · 730 из 1380 ────────┬ 2021 · 815 из 1478 (при сравнении) ┐
│ Ростов-на-Дону        │ 730 (100%) ███████████████ │ 815 (100%) ▒▒▒▒▒▒▒▒▒                │
└───────────────────────┴────────────────────────────┴─────────────────────────────────────┘
… Возраст, Образование, Профессия, Язык программирования*, Грейд, Митапы или сообщество, Откуда узнаёт о митапах*
* можно было выбрать несколько вариантов, сумма процентов может превышать 100 %.
```

«N из M» года — в заголовке его колонки. Отдельного заголовка, повторяющего сводку над страницей, нет. Каждый показанный столбец сортируется, как сейчас.

Столбик — CSS-полоса внутри ячейки шириной `доля × 100 %`. Экранный диктор полосу не читает, число выводится текстом. У года с пустой группой — «count (—)» без полосы.

## «О данных»

Заголовок, оглавление со ссылками на разделы, сами разделы. Боковой панели фильтров и строки года на этой странице нет.

## Пустые и ошибочные состояния

- Нет участников в выбранном году: «В выбранной группе нет респондентов за 2022 год.» + [Все участники].
- Нет компаний за год: «Нет данных о компаниях за 2022 год для выбранной группы.» + [Все участники].
- Ограничение компаний не пересекается с годом: «Для выбранных компаний нет данных за 2022 год.» + [Показать все компании].
- Показатель не выбран (старая ссылка `good=0&wanted=0`): «Показатель не выбран. Выберите показатель оси Y.»
- Ошибка загрузки: «Не удалось загрузить данные. [Повторить]» (как сейчас); сообщение объявляется экранному диктору.
- Сводка при ошибке meta: «Выборка: не удалось загрузить [Повторить]» — не 0.


## Показатель и вид (PR7)

На всех ширинах над данными стоят ограничение компаний, «Показатель» и «Вид».
«Карта / Таблица» показывает одно представление; выбор сохраняется в URL и в «Дублировать».
Три показателя — сумма, «Рекомендуют», «Хотят работать»; у 2019 года только последний.
Старая комбинация двух выключенных флагов показывает предложение выбрать показатель.
Флажка и кругов «доверительного интервала» нет; устаревший параметр `error` в ссылке игнорируется без предупреждения.

Таблица компаний сохраняет семь колонок без колонки N. Высота определяется строками,
по горизонтали прокручивается контейнер, по вертикали — документ. Шапка остаётся у верха
экрана до конца таблицы; колонки совпадают при горизонтальной прокрутке. В PR8 ограничение компаний применяется к обоим видам.


## Компании и поиск (PR8)

Чистое открытие показывает все компании года. Старые ссылки без явного списка — прежние 29,
набор доступен отдельной кнопкой. «Показать все компании» снимает ограничение карты и таблицы.
При пустом пересечении годов и набора показано отдельное сообщение; размер группы остаётся прежним.

«Найти компанию» выделяет одну показанную компанию, сохраняя список и URL. У неё одна подпись
на карте и обведённая строка таблицы; подпись переносится в доступную сторону карты. Цвет букв
фирменный, обводка цветом текста темы 1,5 px, paint-order: stroke, шрифт 600/12 px. Карточка и выбор нажатием точки/строки реализованы в PR9.


## Карточка и близкие точки (PR9)

Нажатие точки или любой ячейки строки, Enter на кнопке-имени и выбор поиска открывают одну карточку.
В ней исходное имя компании, год, три счётчика и доли, «Ответили на вопрос о компании: N» из строки
этой компании; размер группы из сводки его не заменяет. Закрытие снимает выбор; отсутствующий год
показан сообщением без нулей. Ограничение, исключившее компанию, скрывает выбор.

От 1224 px справа от представления стоит колонка 300 px, ниже порога карточка появляется над ним.
При открытии она прокручивается в ближайшую видимую область; смена ширины сохраняет выбор и сортировку.
Наведение и касание показывают подсказку со списком компаний в радиусе 12 CSS px от точки в текущей
геометрии. Список обновляется вместе с данными и размерами карты; точки не сдвигаются. Для выбора
перекрытой компании доступны существующие поиск и таблица. Семь колонок и нативная прокрутка сохранены.

## Сравнение лет и итоговые экраны (PR10)

«Сравнить с» сохраняет второй год в ссылке и действует на компании и состав выборки.
На карте кольца сравнения рисуются раньше точек основного года, легенда различает годы.
Шкала учитывает оба года до ограничения компаний. Выбранная компания выделена в обоих годах;
подпись одна, у основного года или у кольца, если основного нет. В подсказке к имени добавлен год.
Карточка показывает два независимых набора долей, счётчиков и N. Нативная таблица сохраняет
семь колонок и сортирует по основному году; отсутствие строки не превращается в ноль.
При любом из годов 2019 на карте только «Хотят работать», а в таблице только у «Хотят» есть
дельта или сообщение об отсутствии сравнения. Остальные столбцы показывают основной год.
В составе выборки обе колонки имеют собственный знаменатель; год с N=0 показывает «0 (—)» без полос.
На 390 px названия занимают 40 % таблицы, значения с полосами расположены друг под другом.
